# X Watch Timer

X Watch Timer は、X（旧Twitter）の利用時間をトラッキングし、過度な利用を防ぐことでユーザーの自己管理を促進するChrome拡張機能です。Xの閲覧時間をリアルタイムで可視化し、設定した利用時間を超えた場合に通知を行います。

## ✨ 主な機能

- **🕒 リアルタイムの利用時間計測**
  - `x.com` および `twitter.com` へのアクセスを自動で検知。
  - バックグラウンド再生や非フォーカス時の時間は計測せず、**実際に画面を見ている（アクティブな）時間**のみを正確にカウントします。
  - トラッキング中にPCから離れた場合（アイドル状態）の計測自動停止に対応。

- **🖥️ リアルタイム・オーバーレイ表示**
  - Xの画面右上に、本日の利用時間をリアルタイム（1秒更新）で表示。
  - 閲覧の邪魔にならないように透過度を調整し、クリックで一時的に非表示化（最小化）できる非侵襲なデザイン。

- **🔔 使いすぎ防止の通知機能**
  - 設定した利用時間（15分、30分、1時間、2時間）を超過した際に、Chromeのデスクトップ通知機能でお知らせし、休憩を促します。

- **📊 利用履歴の可視化とエクスポート**
  - 拡張機能のアイコンをクリックすると、本日の利用時間と**過去7日間の利用履歴グラフ**（Chart.jsを利用）を確認できます。
  - 集計した履歴データはCSV形式でエクスポート可能。
  - 本日の記録を手動でリセットする機能も搭載しています（デフォルトでは毎日午前0時に自動リセット）。

- **🔒 プライバシー・ファースト設計**
  - 利用データはすべてブラウザのローカルストレージ（`chrome.storage.local`）にのみ保存されます。
  - 外部サーバーへのデータ送信はなく、どのツイートを閲覧しているか等の内容も一切収集しません。

## 🛠️ 技術スタック

- **UI / フロントエンド**: React.js (v18), TypeScript
- **スタイリング**: Tailwind CSS (v4)
- **グラフ描画**: Chart.js / react-chartjs-2
- **ビルドツール**: Webpack (Ts-loader, css-loader, postcss-loader)
- **拡張機能API**: Chrome Extension Manifest V3 (`chrome.storage`, `chrome.tabs`, `chrome.notifications`, `chrome.idle`, `chrome.scripting`)

## 🚀 インストール手順（開発・手動導入）

Chromeウェブストアへ公開する前のローカル環境への手動インストール方法は以下の通りです。

### 1. プロジェクトのビルド
以下のコマンドを実行して、必要なパッケージのインストールとビルドを行います。（Node.jsが必要です）

```bash
# クローンまたはダウンロードしたフォルダに移動
cd X-Watch-Timer

# パッケージのインストール
npm install

# プロダクションビルドを実行。完了すると `dist/` ディレクトリが生成されます
npx webpack --mode production
```

### 2. Chromeブラウザへの読み込み
1. Chromeブラウザを開き、アドレスバーに `chrome://extensions/` と入力してエンターを押します。
2. 画面右上の **「デベロッパーモード」** のスイッチをオンにします。
3. 画面左上に出現する **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. ビルドで生成されたプロジェクト内の `dist/` フォルダを選択して読み込みます。
5. 「X Timer」という拡張機能が一覧に表示されれば、インストール完了です。

## 📖 使い方

1. **トラッキングの開始**: ブラウザでX（x.com または twitter.com）を開くと自動的にトラッキングが開始され、右上に「本日の利用時間」が表示されます。
2. **オーバーレイの最小化**: 右上の時刻表示をクリックすると、小さな時計アイコン（⏱）に最小化されます。再度クリックで元に戻ります。
3. **設定と履歴の確認**: Chrome右上の拡張機能ピースアイコン（🧩）から「X Timer」をクリックすると、ポップアップメニューが開きます。
   - **通知設定の変更**: ドロップダウンから通知の閾値（15分〜2時間）を選択し、「保存」をクリック。
   - **履歴のエクスポート**: 「CSVエクスポート」を押すと `x_timer_history.csv` がダウンロードされます。
   - **リセット**: 「リセット」ボタンで本日の記録を0に戻します。
